Student Roster Installer Builder v1.4.2

This revision supports Inno Setup 7 and falls back to Inno Setup 6.

1. Copy these files into your existing Documents\student-roster folder.
2. Keep your existing .venv.
3. Double-click:
   Build Student Roster Installer v1.4.2.bat
4. The builder will report the Inno Setup compiler it found.
5. Wait for SUCCESS.

Final distributable:
  installer\StudentRoster-Setup-1.4.2.exe

Give only that EXE to the end user.
